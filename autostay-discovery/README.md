# Autostay Discovery

Product discovery skills customized for **Autostay**, an O2O car wash subscription service. Covers ideation, assumption testing, feature prioritization, subscriber/partner interviews, personas, and journey mapping.

## Commands

| Command | Description | Usage |
|---------|-------------|-------|
| `/discover` | Run a full discovery cycle: brainstorm -> assumptions -> prioritize -> experiments | `/discover 예약 시간대 확대 기능` |
| `/interview` | Prepare interview scripts (subscriber/partner) or summarize transcripts | `/interview prep 구독자 이탈 원인 조사` |
| `/triage-requests` | Analyze and prioritize feature requests from subscriber VOC, app reviews, partner feedback | `/triage-requests [paste or upload requests]` |
| `/research-users` | Build subscriber personas and map the customer journey from research data | `/research-users 30대 직장인 구독자` |

## Skills

### Customized for Autostay

| Skill | Description |
|-------|-------------|
| `brainstorm-ideas-existing` | Multi-perspective ideation from PM, Designer, Engineer, Subscriber, and Partner viewpoints. Prioritizes by MRR, Churn, LTV impact. |
| `identify-assumptions-existing` | Devil's advocate analysis across 7 risk areas including O2O-specific risks: Partner Acquisition, Service Quality, Geographic Coverage. |
| `analyze-feature-requests` | Categorize requests into Autostay themes (예약 경험, 세차 품질, 구독 가치, 파트너 경험, 결제/빌링, 앱 UX) with source tagging. |
| `interview-script` | Interview script generator with built-in templates for 구독자 인터뷰 (subscriber) and 파트너 인터뷰 (partner). |
| `user-personas` | Persona builder with pre-built archetypes: 바쁜 직장인, 차량 관리 마니아, 가성비 추구형, 신차 오너. |
| `customer-journey-map` | Journey mapping with pre-built stages: 인지 -> 탐색 -> 가입 -> 이용 -> 유지 -> 확산, including touchpoints, emotions, and O2O loop details. |

### Copied As-Is

| Skill | Description |
|-------|-------------|
| `prioritize-assumptions` | Prioritize assumptions using an Impact x Risk matrix and suggest experiments. |
| `prioritize-features` | Prioritize a feature backlog based on impact, effort, risk, and strategic alignment. |
| `opportunity-solution-tree` | Build an Opportunity Solution Tree (OST) mapping outcomes to opportunities, solutions, and experiments. |
| `summarize-interview` | Summarize an interview transcript into a structured template with JTBD, satisfaction signals, and action items. |

## Usage Examples

### Run a discovery cycle for a new feature area
```
/discover 파트너 세차장 품질 관리 시스템
```

### Prepare for subscriber interviews
```
/interview prep 구독 이탈 원인 조사
```

### Triage a batch of app reviews
```
/triage-requests [paste App Store reviews]
```

### Build personas from survey data
```
/research-users [upload subscriber survey CSV]
```
